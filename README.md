Sistema de Gestión de Reservas y Habitaciones de Hotel

Un sistema por consola desarrollado en Java aplicando los principios fundamentales de la Programación Orientada a Objetos (POO). El proyecto permite gestionar el inventario de habitaciones, el registro de huéspedes y la administración de reservas de un hotel de forma dinámica.

 Características Principales

* Modelado POO Robusto: Aplicación de herencia, clases abstractas e interfaces para estructurar los diferentes tipos de habitaciones (HabitacionSimple, HabitacionDoble, Suite).
* Gestión Dinámica en Memoria: Uso de colecciones (ArrayList) para el manejo eficiente del registro de clientes, historial de reservas e inventario de habitaciones.
* Cálculo Polimórfico de Tarifas: Aplicación de polimorfismo para determinar los costos de estancia según el tipo de habitación, días de hospedaje y cargos adicionales.

 Tecnologías y Herramientas

* Lenguaje: Java 
* Paradigma: Programación Orientada a Objetos (POO)
* Entorno de Desarrollo (IDE): Apache NetBeans
